# React 简历生成器

一个本地运行的 React 简历生成器，支持结构化编辑、头像上传、实时 A4 预览、分类模板切换和浏览器打印导出 PDF。

## 启动

```bash
npm install
npm run dev
```

打开终端里显示的本地地址，通常是：

```text
http://localhost:5173/
```

## 导出 PDF

点击页面中的 `导出 PDF`，在浏览器打印窗口中选择 `另存为 PDF`。

## 部署到 GitHub Pages

仓库已配置 GitHub Actions 自动部署。推送到 `main` 后，到 GitHub 仓库的 `Settings -> Pages`，把 `Build and deployment` 的 `Source` 选择为 `GitHub Actions`。

线上访问地址：

```text
https://ruanchuanli.github.io/resumeBuilder/
```

## 功能

- 上传头像并同步显示到简历模板
- 支持保存多份简历，可新建、切换、复制、重命名和删除
- 姓名、目标岗位、个人优势、技能栈编辑
- 基本信息支持手动新增、删除和命名，例如电话、邮箱、城市、GitHub、博客
- 工作经历、项目经历、教育背景可动态新增和删除
- 模块支持上移、下移、显示、隐藏
- 支持新增自定义模块，并可参与排序和 PDF 导出
- 右侧 A4 预览会按内容高度自动展示多页
- 模板按场景分类：程序员、老师、实习求职、通用商务、创意设计
- 16 套模板：技术清爽、技术清爽单栏、项目导向、代码侧栏、教师档案、学术经典、授课简历、圆角清新、校园蓝、实习投递、商务横幅、商务侧栏、紧凑一页、色块创意、作品集、杂志排版
- `圆角清新` 和 `校园蓝` 参考了你给的两张中文简历图风格
- 8 种强调色
- 数据自动保存到浏览器本地
- A4 打印样式，适合直接生成 PDF
